柯尼发仓储独立站部署说明

1. 将本文件夹内的全部文件和文件夹上传到域名对应的网站根目录。
2. 确保 index.html 位于网站根目录，访问域名即可打开首页。
3. 请保持 assets 文件夹、HTML、CSS、JavaScript 文件的相对目录结构，不要单独移动图片或视频文件。
4. 本网站为纯静态站点，不需要 Node.js、数据库或额外后台服务。
5. 如服务器使用 Nginx 或 Apache，请将网站根目录指向本文件夹，并允许 index.html 作为默认首页。
6. 案例视频文件较大，上传时请确认服务器空间和单文件上传限制足够。

网站入口页面：index.html
